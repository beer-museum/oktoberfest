
## Анимации и мобильная версия

- Страницы адаптированы под экраны от 320 px, включая альбомную ориентацию; кнопки навигации — не меньше 44 px по высоте.
- У каждой пивоварни своя анимация шапки; абзацы и факты плавно появляются при прокрутке, ключевые фразы «прорисовываются» маркером, сверху — полоска прогресса чтения.
- Если в настройках телефона включено «Уменьшение движения», анимации отключаются автоматически. Без JavaScript весь текст тоже виден.

## Оформление

- Иллюстрации, гербы пивоварен, гравюры, схемы и графики нарисованы вектором прямо внутри страниц — внешние картинки и ссылки не нужны. Гербы — оригинальные рисунки в геральдическом стиле, а не официальные логотипы пивоварен.
- Свои фото кружек можно добавить в папку `img/` с именем по номеру экспоната (`394а.jpg`, `396.jpg` …) — они появятся в начале описания автоматически.
